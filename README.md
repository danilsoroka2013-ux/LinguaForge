# LinguaForge ◆ конструктор языковых моделей

Настольное приложение для сборки, обучения и запуска
**собственной языковой модели** — прямо на вашем компьютере, полностью
локально и офлайн.

Рассчитано на скромное железо: обычный процессор (Xeon — отлично),
**2–4 ГБ ОЗУ** и **без GPU вообще**. Ни одного облачного сервиса.

---

## Запуск

```bash
pip install numpy      # единственная зависимость
python main.py         # или double-click run.bat на Windows
```

Требования: Python 3.9+ (проверено на 3.14), tkinter (входит в состав Python
для Windows), numpy.

## Как собрать свою модель за 5 шагов

1. **Данные** — загрузите любой `.txt` (книга, стихи, переписка, документация)
   или нажмите «Демо-корпус».
2. **Токенизатор** — выберите символьный (просто) или BPE (плотнее).
   Нажмите «Обучить токенизатор» — увидите, как текст превращается в числа.
3. **Модель** — подберите размер ползунками или возьмите пресет
   «Мини» (~0.4 млн параметров). Нажмите «Собрать модель».
4. **Обучение** — «Начать обучение» и следите за кривой лосса.
   Чекпоинты пишутся автоматически в `~/.linguaforge/projects/…`.
5. **Песочница** — чат с вашей моделью: она продолжает текст вашим стилем.

Готовая модель — один файл `.lfmodel` (обычно 0.2–2 МБ): в нём веса,
архитектура и токенизатор. Его можно открыть на любом другом компьютере.

## Что внутри (архитектура движка)

```
core/
  tensor.py      мини-тензор с автоградиентом (numpy): matmul, softmax, RoPE-дружелюбные операции
  model.py       трансформер-декодер: pre-LN, RoPE, SwiGLU, каузальная маска, tie-эмбеддинги
  tokenizers.py  символьный токенизатор и обучаемый BPE
  trainer.py     обучение в фоновом потоке: warmup+линейный спад LR, клиппинг, валидация, чекпоинты
  optimizer.py   AdamW
  data.py        загрузка текста (utf-8/cp1251) и батчи случайных чанков
  config.py      сиды, планировщик LR, сохранение/загрузка .lfmodel (npz + JSON-метаданные)
ui/             тема, виджеты (кнопки, слайдеры, график лосса, чат) — чистый tkinter
app/            состояние проекта и главное окно с 6 страницами
```

Модель — честный GPT: многоголовое каузальное внимание, ротационные
позиционные кодировки (RoPE), FFN на SwiGLU, RMSNorm, вес выхода привязан
к входным эмбеддингам. Правильность градиентов подтверждена численной
проверкой (расхождение < 1e-6), обучение на смоук-тесте снижает лосс
с 3.37 до 1.76 за 60 шагов.

## Ориентиры по скорости (на настольном CPU)

| Пресет | Параметры | Скорость обучения | Что умеет после ~2000 шагов |
|---|---|---|---|
| Крошечная | ~70 тыс | ~1500 ток/с | складывает слоги, стиль корпуса |
| Мини | ~400 тыс | ~600 ток/с | короткие фразы «в духе» корпуса |
| Малая | ~900 тыс | ~250 ток/с | связные куски текста, простые диалоги |

Это не ChatGPT: модель на миллион параметров повторяет стиль и структуру
вашего текста, а не рассуждает о мире. Зато она **ваша**, учится на **ваших**
данных и живёт в **одном файле**.

## Частые вопросы

**Можно ли обучать на русском?** Да, корпус и интерфейс рассчитаны на кириллицу.

**Сколько нужно памяти?** Обучение «Мини» занимает меньше 500 МБ ОЗУ.

**Можно ли продолжить обучение позже?** Откройте `.lfmodel` в песочнице
или соберите модель с теми же настройками — загрузка весов сохранена.

**Где мои модели?** `C:\Users\<вы>\.linguaforge\projects\Мой проект\`.
